# SQLL — exelight7 MP3

المشروع الكامل لنسخة **MP3 3.2.4.7**: المصدر، أدوات البناء، الاختبارات، والاعتماديات المصدرية. هذه نسخة نشر أُعيد بناؤها لإزالة مسارات الجهاز من DLL، مع إبقاء كود اللعب مطابقًا لنسخة MP3 المعتمدة.

**[تحميل إصدار MP3](https://github.com/exelight7/SQLL/releases/tag/v3.2.4.7-MP3)** · [دليل البناء](BUILD.md) · [الخصوصية](PRIVACY.md) · [تراخيص المكونات](THIRD_PARTY_NOTICES.md)

## المزايا

- مساعد تصويب عند الضغط على زر التفعيل، مع نطاق وسرعة واستجابة قابلة للتعديل.
- كشف لاعبين ESP: صناديق وأسماء وصحة ومسافة، حسب البيانات المتاحة لدى جهازك.
- واجهة عربية/إنجليزية، مع الحفاظ على خيارات QOL وتحسينات FIX1 وOPT2.
- تبدأ إضافتا التصويب والكشف مطفأتين. تفتح القائمة بـF5، ويوقف F8 الإضافتين فورًا.

الطيران غير منفذ للاعب غير الهوست في الملتيبلاير العام. التصويب والكشف لم يُختبرا داخل قيم عام فعلي؛ الاختبارات المرفقة خارج اللعبة. [التفاصيل والسلوك](README_MP3_AR.md).

## ملفات الإصدار

صفحة الإصدار تحتوي على DLL، أرشيف المصدر الكامل، بصمات SHA256، ونتائج تحقق عامة منزوعة المسارات الشخصية. المصدر يتضمن اعتماديتي MinHook وDetours والخطوط والتراخيص اللازمة للبناء. ملف المترجم الكبير منفصل ورابطه وبصمته في دليل البناء.

السجلات والإعدادات وتقارير الجهاز الخاصة وملفات التفريغ غير منشورة. تستخدم عملية البناء مسارات نسبية داخل التشخيصات المضمّنة، وتُفحص ملفات النشر قبل الرفع. تفاصيل النطاق في [PRIVACY.md](PRIVACY.md).

## البناء

يتطلب Windows وPython 3.12 وLLVM-MinGW x64 UCRT المحدد في [BUILD.md](BUILD.md). الاختبارات لا تشغّل اللعبة أو تتصل بلاعبين، واختبارات الواجهة تمنع إرسال إدخال فأرة.
